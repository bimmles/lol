# Holdout: Four Corners — candidate build

This is a private-test candidate, not a verified release. It adds one TF2 holdout map and a small launcher. The launcher reads the horde cue from the player's installed Left 4 Dead 2 copy at run time; no Valve game sound is included.

Required games: Team Fortress 2 and Left 4 Dead 2.

The launcher starts TF2 with `-insecure` for private/offline testing. Do not connect this client to VAC-secured servers.

The four-player setup, joining, the map in a running game, and Melty's one-click install are not yet tested. This candidate must not be published until those checks are complete.
